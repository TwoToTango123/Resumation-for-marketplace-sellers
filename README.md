# AI Review System for Marketplace Sellers

![tests](https://github.com/TwoToTango123/Resumation-for-marketplace-sellers/actions/workflows/tests.yml/badge.svg)

Telegram-бот, который помогает селлерам Wildberries и OZON отвечать на отзывы.
Собирает новые отзывы, генерирует ответ в тоне бренда через YandexGPT и определяет
тональность, а селлер подтверждает или отклоняет ответ одной кнопкой в Telegram.

Режим модерации (человек подтверждает каждый ответ) — сознательное решение: бот
не отправит от имени бренда ничего, что продавец не одобрил.

## Как это работает

```
Маркетплейс (WB/OZON, пока mock-данные)
        │
        ▼
  сбор отзывов ──► сохранение в Postgres (дедуп по external_id)
        │
        ▼
  YandexGPT ──► черновик ответа + тональность + флаг "нужен человек"
        │
        ▼
  пуш селлеру в Telegram: отзыв + черновик + кнопки ✅ / ❌
        │
        ├─ ✅ ──► публикация на площадку (пока mock)
        └─ ❌ ──► отклонить
```

Фоновый конвейер (APScheduler) собирает и обрабатывает отзывы автоматически,
а команда `/pending` показывает селлеру всё, что ждёт его решения.

## Стек

- **Python 3.13**
- **aiogram 3** — Telegram-бот (роутеры, inline-кнопки, callback-хендлеры)
- **SQLAlchemy 2 + PostgreSQL** — хранение отзывов и ответов
- **YandexGPT** — генерация ответов и анализ тональности
- **APScheduler** — периодический запуск конвейера
- **pytest** — тесты

## Тесты и CI

16 тестов покрывают три уровня:

- **чистые функции** — сборка карточки, разбор ответа модели;
- **моки внешнего API** — логика работы с YandexGPT без реальных запросов в сеть;
- **работа с БД** — CRUD-операции на одноразовой in-memory SQLite.

Прогоняются автоматически через GitHub Actions на каждый push и pull request.

```bash
cd reviews_bot
python -m pytest -v
```

## Запуск

```bash
cd reviews_bot
pip install -r requirements.txt
cp .env.example .env          # заполнить ключи (Telegram, YandexGPT, БД)
python -m db.init_db          # создать таблицы
python -m pipeline            # запустить конвейер
python -m bot.main            # запустить бота
```

## Статус

Учебно-коммерческий проект в разработке. Публикация ответов на маркетплейс пока
работает в mock-режиме: доступ к API Wildberries требует регистрации ИП/ООО,
поэтому последняя миля (реальная отправка ответа) заглушена и включится позже.
