## Продукт

Telegram-бот для селлеров WB/OZON:
- собирает новые отзывы через API маркетплейсов (пока mock-данные)
- YandexGPT генерирует ответ в тоне бренда + определяет тональность
- селлер в Telegram видит отзыв + ответ, жмёт ✅/❌
- (позже) ответ публикуется на площадку через API

Модель: подписка 3000–5000 ₽/мес. Режим модерации (человек
подтверждает каждый ответ) — сознательное решение для доверия.
